1. Difference between Frontend, Backend, and Full-Stack Development
Frontend Development	Backend Development	Full-Stack Development
Deals with the part of the website users see and interact with.	Handles the server, database, and business logic.	Works on both frontend and backend.
Uses HTML, CSS, JavaScript, React, Angular, etc.	Uses Python, Java, PHP, Node.js, .NET, Ruby, etc.	Uses both frontend and backend technologies.
Focuses on user interface (UI) and user experience (UX).	Focuses on data processing, authentication, and APIs.	Builds complete web applications.
Real-World Example: Online Shopping Website
Frontend: Displays products, search bar, shopping cart, and checkout page.
Backend: Processes orders, stores customer information, and handles payments.
Full-Stack Developer: Develops both the shopping interface and the server-side logic.

3. Describe how a browser requests and displays a web page from a web server.

1.The user enters a website address (URL) into the browser.
2.The browser sends an HTTP or HTTPS request to the web server.
3.The web server receives the request.
4.If necessary, the server retrieves data from the database.
5.The server prepares the web page.
6.The server sends HTML, CSS, JavaScript, and other required files back to the browser.
7.The browser downloads these files.
8.The browser renders the page and displays it to the user.

4. Identify and list the tools required to set up a web development environment. Explain the purpose of each.

Visual Studio Code (VS Code): Used to write and edit source code.

Web Browser (Google Chrome, Firefox, Edge): Used to test and display web pages.

Node.js: Provides a JavaScript runtime environment and includes npm for managing packages.

Git: Used for version control and tracking code changes.

GitHub: Used to store and share code repositories online.

Live Server Extension: Automatically refreshes the browser whenever code changes are saved.

Terminal or Command Prompt: Used to execute commands and manage development tools.

5. Explain what a web server is and give examples of commonly used servers.

A web server is software that stores website files and delivers them to users' web browsers when requested over the internet using HTTP or HTTPS.

Common web servers include:

Apache HTTP Server
Nginx
Microsoft IIS
LiteSpeed
Node.js with Express

6. Define the roles of a frontend developer, backend developer, and database administrator in a project.

Frontend Developer:

Designs and develops the user interface.
Creates responsive web pages.
Uses HTML, CSS, and JavaScript.
Ensures a good user experience.

Backend Developer:

Develops server-side applications.
Creates APIs.
Manages user authentication.
Connects the application to databases.

Database Administrator (DBA):

Designs and manages databases.
Ensures data security.
Performs backups and recovery.
Optimizes database performance.

8. Explain the difference between static and dynamic websites. Provide an example of each.

Static Website:
A static website displays the same content to every user. Its pages are created using HTML and CSS, and the content changes only when the files are manually updated.

Example: Personal portfolio website.

Dynamic Website:
A dynamic website generates content based on user interaction or database information. It uses server-side programming languages and databases.

Example: Amazon, Facebook, Instagram, or YouTube.

9. Research and list five web browsers. Explain how rendering engines differ between them.

Five popular web browsers:

Google Chrome
Mozilla Firefox
Microsoft Edge
Apple Safari
Opera

Rendering Engines:

Google Chrome – Blink
Microsoft Edge – Blink
Opera – Blink
Mozilla Firefox – Gecko
Apple Safari – WebKit

Difference: Rendering engines interpret HTML, CSS, and JavaScript to display web pages. Blink is known for high performance, Gecko focuses on web standards and flexibility, while WebKit is optimized for Apple devices and energy efficiency.
